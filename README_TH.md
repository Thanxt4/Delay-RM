# RM Delay — ห้องเย็น (เวอร์ชันติดตั้งบน server บริษัท)

แอปมือถือสำหรับแจ้งวัตถุดิบ Delay ห้องเย็น ตาม W3QCPF18 Rev.17
- ส่องกล้องสดที่สลิป → อ่าน QR ทันที แล้วโชว์ชื่อวัตถุดิบ เกณฑ์ Delay และสถานะ
- PaddleOCR บน server อ่านตัวหนังสือบนสลิป: ชื่อวัตถุดิบ, แผนการผลิต (Code + Line), Batch, กะ, เวลาออกห้องเย็นใหญ่ / เตรียมเสร็จ และ **วันเวลาเข้าห้องเย็นที่เขียนมือ**
- แจ้ง Delay พร้อมรูปหลักฐาน (พิมพ์เวลา กะ พื้นที่ Line สาเหตุลงบนรูป)
- ภาพรวมเปรียบเทียบรายวัน แยกกะ DS / NS, ห้องเย็น, สาเหตุ, Top 5 วัตถุดิบ / Code, Line
- ทุกคนใช้ได้ผ่าน Wi-Fi บริษัท ไม่ต้องมีบัญชี Claude ข้อมูลเก็บในเครื่อง server

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | ตัว server (FastAPI) + OCR + ฐานข้อมูล |
| `static/` | หน้าแอปมือถือ (index.html, ไอคอน, manifest) |
| `gen_cert.py` | สร้างใบรับรอง https (มือถือต้องใช้ https ถึงจะเปิดกล้องได้) |
| `start_server.bat` | ดับเบิลคลิกเพื่อรันบน Windows |
| `requirements.txt` | Python packages ที่ต้องใช้ |

## ติดตั้ง (ครั้งแรก)
1. ติดตั้ง Python 3.10–3.12 (ถ้าเครื่องมีอยู่แล้วจากแอป QC ใช้ตัวเดิมได้)
2. เปิด Command Prompt ในโฟลเดอร์นี้ แล้วรัน
   ```
   pip install -r requirements.txt
   ```
   ถ้าเครื่องมี PaddleOCR อยู่แล้ว (จากเครื่องมือเทียบฉลาก) ใช้ตัวเดิมได้ ไม่ต้องลงซ้ำ
3. สร้างใบรับรอง https — ใส่ IP ของเครื่อง server
   ```
   python gen_cert.py 172.48.2.68
   ```
4. แก้ค่าใน `start_server.bat` ตามต้องการ
   - `RM_DELAY_DATA` = โฟลเดอร์เก็บข้อมูล (ค่าเริ่มต้น `F:\RM_Delay_Data`)
   - `RM_DELAY_PORT` = พอร์ต (ค่าเริ่มต้น 8443)
   - `RM_DELAY_ADMIN_PIN` = PIN สำหรับลบรายการ **เปลี่ยนจาก 0000 ก่อนใช้งานจริง**
5. เปิด Firewall ของ Windows ให้พอร์ต 8443 (Inbound, TCP)
6. ดับเบิลคลิก `start_server.bat`

> **ครั้งแรกที่รัน PaddleOCR จะดาวน์โหลดโมเดลภาษาไทย** (ประมาณ 100–200 MB) เครื่อง server ต้องออกอินเทอร์เน็ตได้ในครั้งแรก
> หลังจากนั้นใช้งานออฟไลน์ได้ ถ้าเครื่องออกเน็ตไม่ได้ ให้ดาวน์โหลดจากเครื่องอื่นแล้วคัดลอกโฟลเดอร์ `%USERPROFILE%\.paddlex\official_models` มาไว้ที่เครื่อง server
> ตรวจสถานะ OCR ได้ที่ `https://172.48.2.68:8443/api/health` (ต้องขึ้น `"ocr":"ready"`)

## ใช้งานบนมือถือ
1. ต่อ Wi-Fi บริษัท แล้วเปิด `https://172.48.2.68:8443`
2. ครั้งแรกเบราว์เซอร์จะเตือนเรื่องใบรับรอง ทำอย่างใดอย่างหนึ่ง
   - **แบบเร็ว:** กด "ขั้นสูง" → "ดำเนินการต่อ" (ต้องทำใหม่เมื่อล้างข้อมูลเบราว์เซอร์)
   - **แบบถาวร (แนะนำ):** เปิด `https://172.48.2.68:8443/rm-delay-ca.crt` เพื่อติดตั้งใบรับรองของบริษัท
     - Android: ตั้งค่า → ความปลอดภัย → การเข้ารหัสและข้อมูลรับรอง → ติดตั้งใบรับรอง → ใบรับรอง CA
     - iPhone: ติดตั้งโปรไฟล์ที่ดาวน์โหลด แล้วไปที่ ตั้งค่า → ทั่วไป → เกี่ยวกับ → การตั้งค่าความเชื่อถือใบรับรอง → เปิด "RM Delay Local CA"
3. อนุญาตกล้องเมื่อถูกถาม
4. เพิ่มไอคอนลงหน้าจอโฮม: เมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอโฮม"

## วิธีใช้
1. เลือกห้องที่ตรวจ (Chill2 … ANTE)
2. กด **ส่องกล้องสแกนสลิป** → ถือให้เห็นสลิปทั้งใบในกรอบ
   - เจอ QR → ชื่อวัตถุดิบ / เกณฑ์ขึ้นทันที (ถ้ารหัสนี้เคยบันทึกแล้ว)
   - OCR อ่านข้อความต่อภายใน 1–5 วินาที → แผนการผลิต เวลาเข้าห้องเย็นที่เขียนมือ ฯลฯ
3. กด **ใช้ข้อมูลนี้** → ตรวจเวลาเข้าห้องเย็น → ถ้า Delay กด **แจ้ง Delay**
4. รหัสวัตถุดิบใหม่: เลือกประเภทตาม WI ครั้งเดียว ครั้งต่อไปแอปรู้เอง (ใช้ร่วมกันทุกเครื่อง)

## ข้อมูลเก็บที่ไหน
ในโฟลเดอร์ `RM_DELAY_DATA`
- `rm_delay.db` — ฐานข้อมูล SQLite (รายการ Delay, รหัสวัตถุดิบ, รายชื่อห้อง/Line)
- `photos\` — รูปหลักฐาน (ชื่อไฟล์ = ID รายการ)
- `slips\` — รูปสลิปที่ส่งมาอ่าน OCR (ไว้ตรวจย้อนหลัง / ปรับปรุงความแม่น) ปิดได้ด้วย `set RM_DELAY_SAVE_SLIPS=0`

**สำรองข้อมูล:** คัดลอกทั้งโฟลเดอร์นี้เป็นระยะ หรือกด "ส่งออก CSV ทั้งหมด" ในแท็บประวัติ

## ให้รันเองตอนเปิดเครื่อง
Task Scheduler → Create Task → Trigger: At startup → Action: Start a program → `start_server.bat` (Start in = โฟลเดอร์นี้)

## ปัญหาที่พบบ่อย
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| กล้องไม่เปิด | ต้องเปิดผ่าน **https** และกดอนุญาตกล้อง |
| `OCR บน server ยังใช้ไม่ได้` | ดูข้อความใน `/api/health` — มักเป็นยังไม่ได้ดาวน์โหลดโมเดล หรือยังไม่ได้ลง paddleocr |
| error `ConvertPirAttribute2RuntimeAttribute` | บั๊ก oneDNN ของ Paddle — ใน server.py ปิด `enable_mkldnn` ไว้แล้ว |
| อ่านชื่อไทยผิด | ถ่ายให้ชัด ไม่เบลอ ไม่สะท้อนแสง แล้วกด "อ่านข้อความอีกครั้ง" |
| มือถือเปิดเว็บไม่ได้ | ตรวจว่า Wi-Fi เดียวกับ server และเปิด Firewall พอร์ต 8443 แล้ว |
